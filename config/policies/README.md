# Policy Configuration

This directory contains policy and governance guidance for the repository.

Phase 1 maintains structure only. The runtime implementation of
escalation-rule and authority-rule enforcement described by this
guidance lives in `packages/policy-engine` (see
[DECISIONS.md](../../DECISIONS.md) ADR-0008 and
[docs/cloud/AI_ROUTING_AND_TOKEN_POLICY.md](../../docs/cloud/AI_ROUTING_AND_TOKEN_POLICY.md)) —
this directory documents policy intent, that package implements it.
